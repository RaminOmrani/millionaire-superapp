# Roadmap — آیتم‌های باز

> این فایل یادآور کارهای باقی‌مانده است. هر بار که فازی تمام می‌شود، وضعیت اینجا به‌روز می‌شود
> و Claude در پایان هر گزارش، بندهای باز را به رامین یادآوری می‌کند.

## ۱) داده‌های قفل (وابسته به رامین) — یادآوری شود
- [ ] تعرفه‌ها و لینک خرید ۴ محصول فعال → حالا از `/admin/products` قابل ورود است (پلن‌ها)
- [ ] آدرس پنل حسابداری (وقتی آماده شد) → از پنل، «ورود به پنل» را فعال کن و لینک بده
- [ ] ۵ تا ۸ ویژگی کلیدی هر محصول → از پنل، فیلد «ویژگی‌های کلیدی»
- [ ] پاراگراف معرفی هلدینگ، آدرس پستی، لینک شبکه‌های اجتماعی (`data.md` §1)
- [ ] توضیح گارسون‌یار و زمان فعال شدنش
- [ ] محتوای «هوش مصنوعی» (تعرفه‌ها، ماژول‌ها)
- [ ] SMTP برای ارسال ایمیل اعلان (`SMTP_*` در `.env` سرور)

## ۴) زیرساخت — یادآوری شود
- [x] اسکریپت بک‌آپ (`deploy/backup.sh`) — نصب cron روی سرور: دستور داخل فایل
- [ ] PR و merge برنچ به `main`
- [ ] Private کردن مخزن + Deploy Key روی سرور برای `git pull`
- [x] اسکریپت یک‌خطی آپدیت روی سرور (`deploy/update.sh`)
- [x] CI (GitHub Actions): lint + typecheck + build روی هر push
- [ ] تعویض `SESSION_SECRET` روی سرور (در اسکرین‌شات دیده شد)

- [x] فاز ۲: هاب محصول، فرم مشاوره، پنل ادمین پایه، دیپلوی
